# 独立插件的执行边界

| 目标 | 当前可行性 | 说明 |
|---|---|---|
| 不碰解包目录开发数据模型 | 可行 | 已在 `src/main` 提供零依赖模型和适配器 |
| 对现成 PC JAR 直接放入 plugin.jar 自动加载 | 不可行 | 0.9.6.5 没有 loader/扫描入口 |
| PC 自定义启动器/Java Agent | 实验可行 | 需要额外启动参数，版本脆弱 |
| Android 直接加载外部 JAR | 不可行 | APK 没有外置插件入口，且有 R8/签名约束 |
| 自有源码构建 PC+Android | 推荐 | 独立模块 + 一次宿主入口，跨端共享 core |
| 外部 companion viewer | 可行 | 可读取导出的数据，但不是游戏内窗口 |
