# 可行性矩阵

| 目标 | 结果 | 说明 |
|---|---|---|
| PC 不修改原游戏 JAR | 可行 | 外置 Java Agent 在启动时注入；需通过 Agent 启动游戏 |
| PC 用现有启动器直接加载普通插件 JAR | 不可行 | 游戏没有外置插件扫描器 |
| Android 通过普通应用注入，不改 APK | 不可行 | App sandbox 不允许一般应用向另一个进程注入 |
| Android 通过 ADB shell 注入，不改 APK | 有条件可行，未实现 | APK 标记 `debuggable=true`；Android 14 有 `am attach-agent`，需原生 JVMTI `.so` 和游戏 UI 桥接 |
| Android root 级注入，不改 APK | 有条件可行，未实现 | LSPosed/Zygisk/Frida 等需单独适配设备、ABI 和系统版本 |
| PC 与 Android 共用同一外置 Agent | 不可行 | Android 使用 ART/Dex 和不同 UI 生命周期 |
| 源码构建版跨端 | 可行 | 是 Android 的非 root 替代方案，但需要产出自有 APK |
