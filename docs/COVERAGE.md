# 覆盖清单

验收目标：PC **0.9.6.5 / 2026100600**。状态以实际输出能力为准：**已文字化**表示已验证指定场景；**需打开页面**表示等待玩家正常打开该页；**需截图**表示没有可靠文字语义；**尚未支持**表示不提供对应功能。每一行的验证范围限定了声明，不能外推为所有分支均已测试。

## 角色、物品与详情

| 信息 | 状态 | 输出与验证范围 |
|---|---|---|
| HUD 属性 | 已文字化 | HP/上限、盾、等级/经验、力量、金币、楼层、位置、饱食、等待操作状态；BoundaryTest 隔离角色 |
| 额外角色属性 | 需打开页面 | 读取 WndHero 当前可见页；默认页和选中标签已验证，不自动切换全部标签 |
| 当前职业、转职与天赋 | 已文字化 | 本局职业名称/说明、已建立天赋树的名称/说明/层级/点数/上限；不枚举隐藏未解锁奖励 |
| 装备和背包 | 已文字化 | 装备位置、数量、显示名、鉴定状态、显示充能等；未知药剂保留外观名 |
| 随身容器 | 已文字化 | containers 保留玩家背包嵌套结构；仅玩家持有容器，不是地面箱子奖励 |
| 隐藏强化/诅咒 | 尚未支持 | 有意不输出；仅 levelKnown/curseKnown 允许时返回相应已知值 |

| 可见状态图标、计数 | 已文字化 | 仅 HUD 可见状态；隐藏被动计数不输出 |
| Bless/Haste/Hunger 说明 | 已文字化 | 精确类型白名单，100 次重复详情读取保持随机数和调度状态 |
| 其他状态、物品特有属性和充能详情 | 需打开页面 | 正常检视后的可见文字；未直接调用未审核详情 |

## 接口与只读保证

| 能力 | 状态 | 验证 |
|---|---|---|
| Agent → HTTP → stdio MCP | 已文字化 | 独立隐藏测试游戏的真实四工具链路；官方 SDK 握手和工具发现 |
| 多调用方游标、重启与缺口 | 已文字化 | 两个真实 stdio 客户端对隔离 HTTP 夹具验证；旧会话/非法序号/重启全量同步 |
| 真实重复日志、字段删除 | 已文字化 | GameLog 钩子重复同文事件；顶层 null 删除；中文增量保留日志 |
| 健康与错误 | 已文字化 | 断开、陈旧、不兼容、畸形响应、错误会话/坐标；不回退旧磁盘数据 |
| 版本绑定截图 | 需截图 | 实际隐藏 GL framebuffer 非空 PNG、物理尺寸、绝对路径、同 session/seq；真实 MCP 请求截图 |
| 坐标换算 | 已文字化 | 当前已发布版本、当前可见、未被窗口/已识别控件遮挡；屏幕外/记忆格/过期版本拒绝 |
| 重复读取无游戏副作用 | 已文字化 | HP、位置、数量、随机数生成器及 Actor 调度指纹前后不变；不等于遍历全部游戏类的形式化证明 |
| Android、自动操作、OCR、模型调用 | 尚未支持 | 第一版边界 |

自定义图形覆盖、所有 DPI/分辨率、全部物品/职业/配方/NPC 分支未逐项穷举。截图测试验证采集机制和像素，不等于为所有游戏画面逐张做过视觉验收。
